# Deadzone (nazwa robocza)

Przeglądarkowa gra survivalowa 3D low-poly w rzucie izometrycznym, inspirowana zasadami Project Zomboid (przetrwanie, rany, infekcja, umiejętności, crafting). Bez żadnych cudzych grafik, tekstur ani dźwięków: tylko własne albo darmowe assety z licencją pozwalającą na użycie komercyjne (CC0).
